            Inbox & EOP Optimization
          

          
Anti-Spam & EOP Deliverability Calculator

          
ประเมินความพร้อมและอัตราการส่งถึง Inbox ตามเกณฑ์มาตรฐาน Google/Yahoo 2024+ และเกณฑ์ Microsoft Defender Anti-Phishing

        


        

          

            
            

              

                

                  

                    
                  

                  

                    
SPF & DKIM Domain Alignment

                    
Envelope From (`MAIL FROM`) ตรงกับ Header `From:` ให้ DKIM สมบูรณ์ (+20%)

                  

                

              


              

                

                  

                    
                  

                  

                    
MIME Multipart Alternative

                    
มีทั้ง Plain Text และ HTML Body คู่กันเสมอตามมาตรฐาน RFC 5322 (+15%)

                  

                

              


              

                

                  

                    
                  

                  

                    
RFC 2047 Thai Header Encoding

                    
เข้ารหัสภาษาไทยแบบ `=?UTF-8?B?...?=` ป้องกัน Header พัง (+15%)

                  

                

              


              

                

                  

                    
                  

                  

                    
Zero-Credential Exposure (EOP Compliant)

                    
ไม่ใส่ Plaintext Password ในอีเมล ป้องกันการโดน Defender กักกัน (+20%)

                  

                

              


              

                

                  

                    
                  

                  

                    
Clean Header Hygiene

                    
ถอด `X-Mailer`, `Auto-Submitted`, `Precedence` ที่ทำให้ M365 กักกัน (+15%)

                  

                

              


              

                

                  

                    
                  

                  

                    
Link Hygiene & Rate Throttling

                    
HTTPS จริง ไม่ใช้ URL Shortener และหน่วงเวลาส่ง 500ms - 1000ms (+15%)

            Corporate Inboxes Diagnostics
          
    
          
    ศูนย์รวมการวิเคราะห์ปัญหาที่พบบ่อย (Troubleshooting Hub)
    
          
    รวมกรณีศึกษาจริงและวิธีแก้ปัญหาการส่งอีเมลเข้า Microsoft 365, Defender Quarantine และ Web Application Auth Fallback
    
        
    

        
    
          
          
    
            
    
              High-Confidence Phishing (SCL 9)
              Admin Quarantine
            
    
            
    อีเมลส่งออกจาก Gmail สำเร็จ แต่ผู้รับใน Outlook ไม่เห็นแม้แต่ใน Junk Mail
    
            
    
              สาเหตุ: ส่งจากอีเมลภายนอก (`@gmail.com`) แล้วใส่ Plaintext Password หรือคำว่า "รหัสผ่านตั้งต้น" + ลิงก์เข้าสู่ระบบภายนอก Defender จัดเป็น Credential Harvesting และกักกันเงียบใน Admin Quarantine
            
    
            
    
              วิธีแก้ไข: ใช้ Zero-Credential Administrative Template ส่งเฉพาะข้อมูลเปิดสิทธิ์และปุ่มล็อกอิน โดยให้ผู้ใช้ใช้รหัสผ่านองค์กรหรือส่งรหัสผ่านผ่านช่องทางอื่น
            
    
          
    

          
          
    
            
    
              NDR 550 5.7.133
              Distribution Group
            
    
            
    ส่งเข้า M365 Group แล้วได้รับอีเมลตีกลับ 550 5.7.133
    
            
    
              สาเหตุ: นโยบายความปลอดภัยเริ่มต้นของ Microsoft 365 Group ปิดกั้นไม่รับอีเมลจากผู้ส่งภายนอกองค์กร (SenderNotAuthenticatedForGroup)
            
    
            
    
              วิธีแก้ไข: รันคำสั่ง Exchange PowerShell: Set-UnifiedGroup -Identity "group@company.com" -RequireSenderAuthenticationEnabled $false
            
    
          
    

          
          
    
            
    
              Group Subscription
              Outlook Behavior
            
    
            
    อีเมลเข้า Group Mailbox กลาง แต่ไม่เด้งเข้า Inbox ส่วนตัวของสมาชิก
    
            
    
              สาเหตุ: สมาชิกใน M365 Group ไม่ได้เปิดการรับสำเนา (Copy to Inbox) หรือมี Header Auto-Submitted: auto-generated ที่ทำให้ M365 ข้ามการส่งต่อ
            
    
            
    
              วิธีแก้ไข: รัน Set-UnifiedGroup -AutoSubscribeNewMembers $true และถอด Header Auto-Submitted ออกจากระบบส่ง
            
    
          
    

          
          
    
            
    
              Silent Auth Fallback
              Frontend Routing Bug
            
    
            
    Frontend ส่งแล้วได้อีเมลรีเซ็ตรหัสผ่านภาษาอังกฤษของ Supabase แทน
    
            
    
              สาเหตุ: Frontend บน Static Hosting (GitHub Pages) เรียก Relative URL /api/send-email (404 Not Found) ทำให้ Client ตกไปเรียก Third-party Auth Fallback
            
    
            
    
              วิธีแก้ไข: กำหนด Absolute Serverless URL บน Vercel พร้อมดึง Dynamic SMTP Settings จาก Database เพื่อส่งผ่าน Native Gmail SMTP
