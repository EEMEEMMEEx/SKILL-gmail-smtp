            Diagnostic & Case Studies
          

          
ศูนย์รวมการวิเคราะห์ปัญหาที่พบบ่อย (Troubleshooting Matrix)

          
รวบรวมกรณีศึกษาจากเหตุการณ์จริง ปัญหาการกักกันของ Microsoft Defender, DBEB Bounces, Dev Proxy 404 และการตั้งค่า Group

        


        

          
          
          
          
        


        

          
          

            

              Phishing Quarantine (SCL 9)
              M365 Defender
            

            
ส่งสำเร็จจาก Gmail (250 OK) แต่ไม่เข้า Inbox และไม่พบใน Junk

            

              สาเหตุ: ใช้คำเตือนภัยรุนแรง (*"เตือนภัย:"*, *"ด่วนที่สุด"*) หรือใส่รหัสผ่านคู่กับลิงก์ภายนอก ทำให้ AI ของ Defender กักกันเข้า Admin Quarantine
            

            

              วิธีแก้ไข: ใช้ภาษาทางการของการจัดการพัสดุ (เช่น *"แจ้งเตือนรายการพัสดุถึงจุดสั่งซื้อ"*), ปรับกล่องข้อความเป็นสี Amber และไม่ระบุรหัสผ่านในอีเมล
            

          


          
          

            

              HTTP 404 / SPA Fallback
              Local Development
            

            
กดส่งอีเมลจาก Webapp ในเครื่อง Dev แล้วแจ้ง Error 404 Not Found

            

              สาเหตุ: ไฟล์ `api/send-email.js` เป็น Serverless Function ซึ่ง Vite Dev Server ในเครื่องไม่ได้แมปเส้นทาง จึงส่งกลับเป็นไฟล์ `index.html` แทน
            

            

              วิธีแก้ไข: ติดตั้ง Dev Proxy หรือ Middleware ใน `vite.config.js` เพื่อดักจับเส้นทาง `/api/send-email` ส่งต่อไปยัง Local Serverless Runtime
            

          


          
          

            

              NDR 550 5.4.1 Access Denied
              Directory Edge Blocking
            

            
อีเมลถูกตีกลับ 550 5.4.1 Recipient address rejected: Access denied

            

              สาเหตุ: ฟีเจอร์ DBEB ของ Microsoft 365 สกัดกั้นที่อยู่อีเมลผู้รับที่ไม่มีอยู่จริง หรือยังไม่ได้ถูก Provisioning ใน Entra ID
            

            

              วิธีแก้ไข: ตรวจสอบความถูกต้องของชื่อ Mailbox/Alias กับผู้ดูแลระบบ Exchange ปลายทาง และเพิ่มที่อยู่ผิดเข้า Suppression List
            

          


          
          

            

              NDR 550 5.7.133
              Distribution Group
            

            
ส่งเข้า M365 Group แล้วได้รับอีเมลตีกลับ 550 5.7.133

            

              สาเหตุ: Microsoft 365 Unified Group ปิดรับอีเมลจากผู้ส่งภายนอกองค์กรโดยเริ่มต้น (SenderNotAuthenticatedForGroup)
            

            

              วิธีแก้ไข: ให้ Exchange Admin รันคำสั่ง `Set-UnifiedGroup -Identity "group@company.com" -RequireSenderAuthenticationEnabled $false`
            

          


          
          

            

              SMTP 535 / EAUTH
              Authentication Failure
            

            
การเชื่อมต่อล้มเหลวด้วยข้อผิดพลาด Invalid Credentials (535)

            

              สาเหตุ: ใช้รหัสผ่านบัญชี Google จริง หรือ Google App Password 16 หลักถูกเพิกถอน / คอนฟิก Port และ TLS ไม่ตรงกัน
            

            

              วิธีแก้ไข: สร้าง Google App Password ใหม่ผ่านบัญชี Google ที่เปิด 2-Step Verification และใช้ Port 465 (Implicit TLS)
            

          


          
          

            

              DB State Override
              Database Sync
            

            
แก้โค้ดแม่แบบในไฟล์แล้ว แต่หน้าเว็บยังคงดึงข้อความเก่ามาแสดง

            

              สาเหตุ: ฟังก์ชัน Fetch Settings ดึงข้อมูล JSON แม่แบบเก่าที่เคยบันทึกไว้ใน Supabase Database มาเขียนทับ Default Config ในโค้ดใหม่
            

            

              วิธีแก้ไข: ติดตั้งฟังก์ชัน `mergeEventsWithDefaults` เพื่อ Auto-Upgrade แม่แบบเก่า และเพิ่มปุ่ม Reset to Default บนหน้าเว็บ
